# Posting instructions: WeAdU Shopping feed check (PrestaShop forum)

*Version française plus bas.*

## English

### Before you post

- Wait until the WeAdU team tells you the module is released and sends you the file `weadushoppingfeed.zip` and the GitHub link. Until then, do not post anything.
- Use your own PrestaShop forum account. Do not create extra accounts.
- Read the rules of each section before posting (links below). They can change: if they say something different from this page, follow the forum rules and tell the WeAdU team.

### Where to post

| Place | What to post | Notes |
| --- | --- | --- |
| French forum, section **Modules et thèmes gratuits** (https://forum.prestashop.com/forum/147-modules-et-th%C3%A8mes-gratuits/) | `post-fr.md`, one topic | Attach the ZIP to the first message. |
| English forum, section **Free Modules & Themes** (https://forum.prestashop.com/forum/144-free-modules-themes/) | `post-en.md`, one topic | Attach the ZIP to the first message. |

### Forum rules to respect

- Attach the module ZIP to the first message. The sections ask for this.
- External links: the section headers allow another link only if it points directly to the module **and** your account has at least 100 forum posts. If your account has fewer than 100 posts, delete the line "Code source : LINK" from the French message (the English message has no link).
- No link to a shop, a marketplace home page, or the WeAdU website in the message. The module and its GitHub page are enough.
- The forum is not an advertising space: keep the text factual, as written.
- Never send private messages to members to promote the module.
- Read the general French forum rules: https://forum.prestashop.com/topic/256108-regle-du-forum-officiel-de-prestashop-et-conseils-dutilisation-a-lire/ and the section rules: https://forum.prestashop.com/topic/516467-avant-de-poster-veuillez-lire-les-r%C3%A8gles-dutilisation-concernant-cette-section/
- One topic per section. Do not copy the message into other sections or into other people's topics.
- Do not add claims that are not in the message: no user numbers, no ratings, no features that are not listed.

### After posting

- Answer questions **only in our own topics** (the French one in French, the English one in English). Do not reply in other people's topics to mention the module.
- Before answering, ask the person for their PrestaShop and PHP versions if they report a problem, and pass the details to the WeAdU team.
- Feature requests: thank the person, say we have noted it, and tell the WeAdU team. Do not promise a date.
- If a moderator asks for a change or moves or removes the topic, accept it and tell the WeAdU team. Do not repost.
- Send the WeAdU team the links to both topics.

## Français

### Avant de publier

- Attendez que l'équipe WeAdU vous confirme que le module est publié et vous envoie le fichier `weadushoppingfeed.zip` et le lien GitHub. D'ici là, ne publiez rien.
- Utilisez votre propre compte sur le forum PrestaShop. Ne créez pas de compte supplémentaire.
- Lisez les règles de chaque section avant de publier (liens ci-dessous). Elles peuvent changer : si elles diffèrent de cette page, suivez les règles du forum et prévenez l'équipe WeAdU.

### Où publier

| Endroit | Quoi publier | Remarques |

### Règles du forum à respecter

- Joignez le ZIP du module au premier message : c'est ce que demandent ces sections.
- Liens externes : l'en-tête des sections n'autorise un autre lien que s'il pointe directement vers le module **et** si votre compte totalise au moins 100 messages sur le forum. Si votre compte en totalise moins de 100, supprimez la ligne « Code source : LINK » du message français (le message anglais ne contient pas de lien).
- Aucun lien vers une boutique, la page d'accueil d'une place de marché ou le site de WeAdU dans le message. Le module et sa page GitHub suffisent.
- Le forum n'est pas un espace publicitaire : gardez le texte factuel, tel qu'il est rédigé.
- N'envoyez jamais de message privé aux membres pour présenter le module.
- Lisez les règles générales du forum francophone : https://forum.prestashop.com/topic/256108-regle-du-forum-officiel-de-prestashop-et-conseils-dutilisation-a-lire/ et les règles de la section : https://forum.prestashop.com/topic/516467-avant-de-poster-veuillez-lire-les-r%C3%A8gles-dutilisation-concernant-cette-section/
- Un seul sujet par section. Ne copiez pas le message dans d'autres sections ni dans les sujets des autres.
- N'ajoutez aucune affirmation absente du message : pas de nombre d'utilisateurs, pas de notes, pas de fonctionnalités non listées.

### Après la publication

- Répondez aux questions **uniquement dans nos propres sujets** (le sujet français en français, le sujet anglais en anglais). Ne répondez pas dans les sujets des autres pour mentionner le module.
- Si quelqu'un signale un problème, demandez-lui ses versions de PrestaShop et de PHP, puis transmettez les détails à l'équipe WeAdU.
- Demande de fonctionnalité : remerciez la personne, dites que c'est noté et prévenez l'équipe WeAdU. Ne promettez pas de date.
- Si un modérateur demande une modification, déplace ou retire le sujet, acceptez-le et prévenez l'équipe WeAdU. Ne republiez pas.
- Envoyez à l'équipe WeAdU les liens des deux sujets.
